# Simple Todo

프레임워크·빌드 도구 없이 순수 HTML/CSS/JavaScript(ES 모듈)로 만든 개인용 할일 관리 앱입니다. 하루 10~20개 수준의 할일을 카테고리별로 빠르게 기록·체크하고, 진행률을 한눈에 파악하는 것을 목표로 합니다.

## 주요 기능

- **할일 추가 / 수정 / 삭제** — 입력창 + Enter(또는 추가 버튼)로 등록, 더블클릭 또는 수정 아이콘으로 인라인 수정, 삭제 시 확인창
- **완료 체크** — 체크박스로 완료/미완료 토글, 완료 항목은 취소선 표시 후 목록 하단으로 정렬
- **카테고리 분류 (업무 / 개인 / 공부)** — 색상 태그로 구분, 필터 버튼으로 카테고리별 목록 좁혀보기
- **키워드 기반 자동 카테고리 추천** — "회의", "장보기", "영어 단어"처럼 제목에 포함된 키워드를 보고 카테고리를 자동으로 선택 (직접 선택하면 그 값이 우선)
- **진행률 표시** — 전체 완료율과 카테고리별 완료 현황을 프로그레스 바 + 텍스트로 표시
- **다크모드** — OS 설정을 기본으로 따라가며, 토글 버튼으로 직접 전환 가능 (선택값은 저장되어 다음 방문에도 유지)
- **데스크톱 레이아웃** — 좁은 모바일형 화면(`index.html`)과 별도로, 넓은 화면에 맞춘 사이드바 + 카드 그리드 레이아웃(`web_version/`) 제공
- **새로고침해도 유지되는 데이터** — 브라우저 `localStorage`에 저장, 별도 로그인·서버 없이 동작

## 실행 방법

빌드 과정이 없으므로 정적 파일 서버로 열기만 하면 됩니다. (ES 모듈은 `file://`로 직접 열면 브라우저 보안 정책 때문에 동작하지 않습니다.)

```bash
npx serve
```

터미널에 출력된 주소로 접속하면 모바일형 레이아웃(`index.html`)이 뜨고, 같은 서버의 `/web_version/` 경로로 접속하면 데스크톱 레이아웃이 뜹니다. 두 화면은 같은 브라우저(같은 origin)에서 열면 `localStorage`를 공유하므로 데이터가 서로 연동됩니다.

## 어떻게 구현되었나

React나 Vue 같은 프레임워크, Webpack/Vite 같은 빌드 도구를 전혀 쓰지 않고, `<script type="module">`과 ES 모듈 `import`/`export`만으로 구성했습니다. 각 파일은 역할이 하나로 고정된 작은 모듈입니다.

```
index.html          → 모바일형(좁은 화면) 레이아웃
css/style.css        → 모바일형 스타일 (CSS 변수로 라이트/다크 팔레트 정의)
web_version/
  index.html         → 데스크톱형(넓은 화면) 레이아웃 — js/는 그대로 재사용
  css/style.css       → 데스크톱형 스타일
js/
  storage.js         → localStorage 읽기/쓰기만 담당 (persistence)
  todos.js           → 할일 배열 상태 관리 + pub/sub (addTodo/updateTodo/deleteTodo/toggleComplete)
  categorize.js      → 제목 키워드로 카테고리를 추측하는 순수 함수
  theme.js           → 라이트/다크 테마 결정·저장·전환
  app.js             → 유일하게 DOM을 다루는 모듈, 위 모듈들을 엮어서 렌더링
```

- **상태 관리**: `todos.js`가 할일 배열을 들고 있다가, 값이 바뀔 때마다(`addTodo` 등) `localStorage`에 저장하고 구독자(`subscribe`)에게 알립니다. React의 상태 관리 라이브러리 대신 이 최소한의 pub/sub 패턴 하나로 전체 UI 갱신을 처리합니다.
- **렌더링**: `app.js`는 상태가 바뀔 때마다 `#todo-list`를 통째로 비우고 다시 그립니다. 가상 DOM이나 diffing 없이, 지금 규모(하루 10~20개)에서는 이 방식으로 충분하다는 판단입니다.
- **모바일/데스크톱 두 화면**: 두 `index.html`은 같은 요소 ID(`#todo-list`, `#todo-form` 등)를 쓰기 때문에, 레이아웃(HTML/CSS)만 다르고 로직(`js/app.js` 등)은 완전히 공유합니다. 즉 기능을 추가할 때 로직 코드는 한 곳만 고치면 두 화면에 모두 반영됩니다.
- **다크모드**: 색상을 하드코딩하지 않고 CSS 커스텀 프로퍼티(변수)로 선언한 뒤, `<html data-theme="dark">`일 때 다크 팔레트로 값만 바꿔치기합니다. 사용자가 따로 선택하지 않았다면 OS의 다크모드 설정을 실시간으로 따라갑니다.
- **카테고리 자동 추천**: `categorize.js`가 제목 문자열에 미리 정의된 키워드(업무/개인/공부별 목록)가 포함되어 있는지 검사해서 카테고리를 추측하는 순수 함수입니다. 입력창에 타이핑할 때마다 호출되며, 사용자가 카테고리를 직접 선택하면 그 이후로는 자동 추천을 멈춥니다.

더 자세한 요구사항과 단계별 구현 과정은 [`docs/PRD.md`](docs/PRD.md), [`docs/IMPLEMENTATION_PROMPTS.md`](docs/IMPLEMENTATION_PROMPTS.md)에, Claude Code용 아키텍처 메모는 [`CLAUDE.md`](CLAUDE.md)에 정리되어 있습니다.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 마크업/스타일 | HTML5, CSS3 (커스텀 프로퍼티 기반 테마) |
| 로직 | 순수 JavaScript (ES 모듈), 프레임워크 없음 |
| 데이터 저장 | 브라우저 `localStorage` |
| 빌드 도구 | 없음 |
